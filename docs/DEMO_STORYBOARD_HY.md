**Կարևոր.** Սցենարի թվերը փոխվում են ամեն Meta գործարկման ժամանակ։ Նկարահանման պահին էկրանի և խոսքի թվերը պետք է համընկնեն։ Եթե Meta-ն այլ ռիսկ է վերադարձնում, համապատասխան տեքստը փոխիր։

**Ներկայացրու միայն հաքաթոնի ընթացքում կառուցված հնարավորությունները։** Կարճ տեխնիկական հատվածում ընդգծիր Muse Spark 1.3 API, tool calling, deterministic JavaScript calculators, 64 automated tests։

Նախ նկարահանիր էկրանը, հետո առանձին ձայնագրիր խոսքը։ Պատրաստի տեսանյութը պահիր 3 րոպեի սահմանում և ստուգիր URL-ի հանրային հասանելիությունը։
