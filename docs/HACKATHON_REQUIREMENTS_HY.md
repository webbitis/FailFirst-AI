# Meta Global AI Developer Hackathon 2026. Մասնակցի պայմանների ստուգում

Ստուգված է 2026-10-31-ին։ Հիմնական մանրամասն պահանջները վերցված են **Participant Guide-ի այն հատվածներից, որոնք մասնակիցը փոխանցել է հոկտեմբերի 26-ին**։ Դրանք ավելի մանրամասն են, քան հրապարակային կայքը։ Վերջնական ներկայացումից առաջ համեմատել պորտալի ընթացիկ կանոնների հետ։

## Հաստատված՝ Participant Guide-ից

- [x] **Public GitHub repository**. կոդի հղումը պետք է բացվի առանց մուտքի հատուկ թույլտվության։
- [x] **3-րոպեանոց demo video**. տեսանյութը պետք է հասանելի լինի ժյուրիին։ Մեր նախկին 2-րոպեանոց սցենարը բավարար չէ։
- [x] Submission-ը կատարվում է **Cerebral Valley հարթակով**, վերջնաժամկետը՝ **2026-11-04, 21:00 ET = 2026-11-05, 06:00 Հայաստանի ժամանակով**։ Ուշ submissions չեն ընդունվում։
- [x] Մեկ submission յուրաքանչյուր անհատ/թիմ/startup-ի համար։ Անհատական մասնակցությունը թույլատրված է։ Առավելագույն թիմը 4 հոգի է, բոլոր մասնակիցները պետք է նշվեն։
- [x] **Demo-ում ցուցադրել միայն հաքաթոնի ընթացքում ստեղծված աշխատանքը** և հստակ նշել նոր ստեղծած մասերը։ Նախկին կոդի ընդլայնումը թույլատրելու startup բացառությունը ինքնաբերաբար չի տարածվում Indie նախագծի վրա։
- [x] Պետք է իրավունքներ ունենալ ներկայացված **կոդի, տվյալների և մեդիա նյութերի** նկատմամբ։ Անթույլատրելի նյութերը և կանոնների խախտումները կարող են բերել որակազրկման։
- [x] **Stage 1 (pass/fail)**. թեմային համապատասխանություն և Meta Model API կամ Meta open-weight մոդելների իրական, հիմնավորված օգտագործում։
- [x] **Stage 2 (0–10 միավոր)**. Impact **30%**, Meta AI Tooling **25%**, Technical Depth & Execution **20%**, Demo **25%**։ Լավագույն 5 նախագիծը յուրաքանչյուր track-ից անցնում է եզրափակիչ փուլ։

## Հաստատված՝ պաշտոնական հրապարակային էջերից

- Indie Developer track. ստեղծարարություն, տեխնիկական հավակնություն և աշխատող արդյունք։
- Build for Your World թեման համապատասխանում է բիզնես որոշումների stress-testing նախագծին։
- Meta Model API և Muse Spark մոդելների օգտագործումը մրցույթի տեխնիկական ուղղության մեջ է։
- Հայաստանը հրապարակային էջի արգելված երկրների անվանական ցուցակում նշված չէ, սակայն անձնական իրավունակությունը և մրցանակի ստացումը կարգավորվում են ամբողջական Official Rules-ով։
- Official Rules-ի ընդունումը պարտադիր է ընտրված մասնակիցների համար։

Պաշտոնական էջեր՝
- https://cerebralvalley.ai/e/meta-ai-developer-hackathon
- https://dev.meta.ai/events/global-hackathon
- https://cerebralvalley.ai/e/meta-ai-developer-hackathon/waiver

- [ ] Submission ձևի ճշգրիտ դաշտերը, repo/video URL-ի պահանջվող ձևաչափերը։
- [ ] Demo video-ի **ճշգրիտ առավելագույն տևողությունը և հոստինգի/ֆայլի պահանջները**։ Participant Guide-ը նշում է 3 րոպե. պատրաստել մինչև 3 րոպե, եթե dashboard-ը այլ բան չի պահանջում։
- [ ] Live deployment URL պարտադի՞ր է, թե GitHub + video բավարար է։ Հրապարակային էջում հստակ չէ։
